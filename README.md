# Chroma Hero

Choose your own colors!
## Controls
Go to settings menu where you normally choose your color and click the mini-preview once.
A color picker window will open. Drag its sliders to set the color, the box next to them shows the result:
- Color
- Saturation
- Brightness

Or use the arrow keys:
- Up / Down arrow: Cycle color
- Left / Right: Change brightness

Press the window's Continue button to save your color and close the picker.

## Rainbow mode
Set `Rainbow=1` in the `[ChromaHero]` section of `options.ini` (next to `Loop Hero.exe`) to make the hero cycle through all colors.
It keeps the saturation and brightness you picked, so pick a saturated color for the full rainbow.
